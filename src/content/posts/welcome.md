This is a sample blog post. To add a new post:

1. Create a new `.md` file in `src/content/posts/` (e.g. `my-post.md`).
2. Add frontmatter at the top with `title`, `date`, and optional `excerpt`.
3. Write your content in Markdown below the frontmatter.
4. Commit and deploy — the post will appear on the blog index automatically.

You can use **bold**, *italic*, [links](https://example.com), and more.
